# CS2 人机增强助手 0.6.2 更新日志

【新增】

- 新增内置定制资源包的多布局定位与内容校验，安装器在不同 Tauri 资源目录结构下都能优先找到包含根级 `gameinfo.manifest.json` 的有效资源包。
- 新增资源包内置回退能力；当安装目录中的资源文件缺失或布局变化时，程序可从内置资源恢复后再继续安装校验。
- 新增 Steam 启动权限兼容处理，遇到明确的管理员权限错误时仅对 Steam 本身请求系统提升，不让助手整体以管理员身份运行。
- 新增已保存 CS2 目录的复核逻辑；自动扫描暂时没有找到 Steam 库时，只要已保存目录仍然有效，就继续按已确认目录使用。

【优化】

- 优化定制资源包 ZIP 条目读取与路径归一化，兼容带有 `./` 前缀的归档条目，同时继续拒绝越界路径和不可信资源。
- 优化 BOT 难度资源包，补齐 Low、Medium、High 及默认难度所需的 `botprofile.vpk` 文件，并增加安装器契约校验。
- 优化库存换肤安装流程：CounterStrikeSharp 尚未首次生成 `core.json` 时不再误报基础环境缺失，启用库存换肤时会保留已有字段并补齐所需配置。
- 优化 CS2 目录扫描、安装资源验证和 Panel 启动链路的错误提示，使用户能够明确知道是目录、资源、权限还是运行状态问题。
- 优化账号登录与支持服务的异常处理，保留既有账号、密码和禁用状态校验，并减少桌面端对服务端状态的误判。

【修复】

- 修复库存换肤页面在 CounterStrikeSharp 已安装、但 `core.json` 尚未生成时持续显示“先补齐基础环境”，导致无法安装库存模拟器的问题。
- 修复库存换肤插件启用前无法自动准备 `FollowCS2ServerGuidelines=false` 的问题，避免首次使用时被服务端默认配置阻断。
- 修复部分安装布局下找不到内置 `CS2BotImprover.zip`，或误选到不完整 ZIP 后直接失败的问题。
- 修复 BOT 难度切换读取 `overrides/Low/botprofile.vpk`、`Medium`、`High` 和默认 VPK 时文件缺失的问题。
- 修复 Steam 安装器带有 `requireAdministrator` 清单时，助手直接启动失败的问题。
- 修复 Steam 自定义库扫描为空时覆盖有效已保存目录、错误提示“未找到目录”的问题。

【其他】

- 正式版本号更新为 `0.6.2`。
- 本版本继续使用 Tauri updater `.sig` 作为更新包签名；Windows NSIS 安装器的 Authenticode 状态与 updater 签名分开记录。
- 本版本保留 CounterStrikeSharp、Inventory Simulator 及定制资源包的原有许可证、版权和归属信息。
- 库存换肤仍仅面向助手启动的本地 `-insecure` BOT 对局，不适用于官匹、5E、完美或其他受保护环境。
- 真实 CS2 安装、启动、库存同步和游戏内效果仍需在目标玩家设备完成最终验收。
