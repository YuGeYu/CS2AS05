# CS2 人机增强助手 0.5.8 更新日志

【新增】赛后 Demo 解析完成后自动生成对局报告，并支持独立战报窗口查看。
【新增】对局报告新增表现雷达，展示火力、输出、生存、参战、协同、先手影响六个维度。
【新增】对局报告新增公告中心，支持成功、警告、错误三种公告强度及未来发布时间。
【优化】赛后会话改为连续确认 CS2 已稳定退出，减少主动退出时的瞬时误判。
【优化】Demo 扫描、导入、任务领取和报告提交统一经过退出稳定门禁，避免解析器读取未写完的录像。
【优化】安装与诊断、维护与求助页面重新整理，客服运行时才显示浮动操作圆钮。
【修复】修复 CS2 仍在运行时偶发进程漏检，导致 Demo 只进行一两回合便提前结算的问题。
【修复】修复重复刷新 Demo 监听目录时旧 watcher 未及时停止，造成同一录像重复调度的问题。
【修复】修复记分板比分来源不一致时的早期结算和报告状态回退问题，保留旧报告兼容性。
【其他】表现雷达仅用于可视化分析，不生成新的 Rating、不参与 MVP 或记分板排序，也不替换 `simple-rating-v1`。
