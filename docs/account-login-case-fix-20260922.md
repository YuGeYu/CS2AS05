# 官网账号重新登录修复 · 2026-09-22

## 反馈与定位

- 本轮是 CS2AS05 的 0.5.15 开发工作，不调整仓库现有版本字段、不新建分支。
- 玩家反馈：官网一键生成账号后无法再次登录，站长账号正常。聊天中的 QQ 本地图片未取得，未将图片内容作为判断依据。
- 助手的登录、故障账号自动注册、玩家圈子认证均使用 `https://cs2as.600318.xyz`；实际认证实现位于配套项目 `E:\cs2as\src\worker.ts`。
- 根因：`createQuickAccount` 把 `小猫Mimi123` 一类大小写混合用户名原样写入 SQLite/D1，而 `login` 使用 `normalizeUsername` 转为小写后执行区分大小写的查询。注册直接签发会话，所以首次可用；重新登录查询不到用户而返回 401。手动注册和站长初始化原本会规范化用户名，因此不受此问题影响。

## 修复

1. 新的一键注册账号统一规范化用户名；手动注册和一键注册查重使用 `COLLATE NOCASE`，避免与历史账号形成仅大小写不同的重名。
2. 登录优先精确匹配玩家输入的用户名（只去掉首尾空白），没有精确匹配时才查找唯一的大小写不敏感匹配，兼容旧自动账号。
3. 若历史上已经有仅大小写不同的多个账号，必须使用原始准确用户名；不随机选账号，不在密码错误或账号被禁用后尝试另一账号。
4. 密码继续严格区分大小写。没有修改用户 ID、用户名、密码、权限或历史数据，也不需要数据库迁移。
5. 修复落在官网公共认证接口，旧助手同样受益，无需为本次问题重新打包安装器。没有新增 localStorage 使用，也没有改动界面。
