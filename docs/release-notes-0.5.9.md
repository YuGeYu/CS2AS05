# CS2 人机增强助手 0.5.9 更新日志

【新增】库存换肤全面升级为 Inventory Simulator 3.1.0，在网页创建并装备库存后，即可用于助手启动的本地 BOT 对局。
【新增】库存换肤新增环境检测、一键启用、中文教程、打开饰品工坊与安全移除，插件、配置和游戏状态一目了然。
【新增】插件主包加入 MapRotation 地图轮换能力，安装或更新助手插件后即可使用。
【新增】表现雷达支持展示超过 100 分基准圈的极端突出表现，最高显示到 140 分。
【新增】简易 Rating 升级为 `simple-rating-v2`，按每回合击杀、伤害和助攻评估实际比赛影响，避免低产出保活玩家因低死亡数获得过高评分。
【新增】主题设置加入“取消开屏动画”，并扩展紧凑、标准、宽松布局与全局圆角调节范围。

【优化】饰品系统改为单一换肤引擎，迁移时精确清理旧 PlayerSkinMod 与旧饰品缓存，避免两套插件同时修改武器实体。
【优化】紧凑布局减少侧栏、状态栏和内容留白，宽松布局增加阅读空间，让不同窗口尺寸都更顺手。
【优化】开屏鸣谢与贡献陈列馆扩大场景、展牌环和镜头活动范围，陈列内容更舒展清晰。
【优化】表现雷达以 100 分为稳定基准，仅让真正突出的数据受控越界，普通对局仍保持易读比例。
【优化】战报、主题设置、安装诊断和库存换肤继续统一暗色与浅色视觉变量，界面切换更一致。

【修复】修复开屏动画及贡献陈列馆中相邻展牌折叠、互相遮挡的问题。
【修复】修复库存换肤移除后可能残留插件配置或 gamedata 的问题，并加入固定路径白名单与目录边界校验。
【修复】修复 CS2 运行期间仍可移除库存换肤插件而可能造成文件占用或状态异常的问题。
【修复】修复表现雷达超过基准时，前端图形与显示数值被错误压回 100 的问题。
【修复】修复旧版 K/D 比率权重过高导致低死亡、低产出玩家评分反超高击杀高伤害玩家的问题。

【其他】库存换肤服务于助手启动的 `-insecure` 本地 BOT 场景，不用于官匹、竞技平台或受 VAC 保护的对局。
【其他】本版本安装程序提供 Tauri updater `.sig` 更新签名；该签名与 Windows Authenticode 代码签名属于不同机制。
