# CS2 人机增强助手 0.5.13 更新日志

【新增】新增水墨江南 Three.js 鸣谢长廊，开屏动画与版本彩蛋共用同一场景，依次展示上游项目、公开赞助与公开鸣谢。
【新增】新增按牌子数量自适应的长廊布局，支持上游项目、赞助与鸣谢数量动态增加、减少和类别为空。
【新增】新增“只开换肤”启动模式，保留 Inventory Simulator，同时隔离 CS2AS05 管理的 BOT 插件。
【新增】新增 BOT 强度工坊编辑文本结构校验和独立的重打包失败、回读失败错误分类。
【新增】Demo 复盘新增战术回放工作台，整合地图回放、热力图、上下文状态、时间轨和空间数据检查器。
【新增】概览页升级为本地对局启动台，集中显示 CS2 目录、资源环境、进程状态、启动模式和主要操作。

【优化】开屏动画默认关闭，保留用户已有的明确设置；用户可以在设置中按需开启，或从版本彩蛋进入同一鸣谢长廊自由浏览。
【优化】鸣谢牌面按来源使用青黛、暖金和朱砂视觉区分，并优化牌子数量变化后的镜头聚焦、间距和可读性。
【优化】恢复上游 CS2-Bot-Improver v1.4.4 的 NadeSystem 投掷行为，移除项目额外的投掷节奏、开局预算、每回合数量和队伍烟雾限制。
【优化】只开换肤模式增加插件隔离与恢复状态记录，支持切回 BOT 模式或 Online 模式时恢复受管文件。
【优化】窄窗口下的预览、概览、状态条、鸣谢导航和战术工作台采用响应式布局，保留关键操作、焦点状态和减少动效支持。

【修复】修复鸣谢数量变化后牌子可能互相遮挡、空类别残留、彩蛋镜头无法定位以及大数量导航横向溢出的问题。
【修复】修复开屏和彩蛋场景分别维护布局导致牌子顺序、数据和视觉表现不一致的问题。
【修复】修复 BOT 强度工坊候选 VPK 原地修改后偶发提取回读失败的问题。
【修复】修复 CS2 残留挂起进程导致助手持续锁定 Panel、BOT 工坊和其他本地配置操作的问题。
【修复】修复创意工坊闯关地图中 BOT 行为被 CS2AS05 接管，导致 BOT 全灭后地图无法正常推进下一关的风险。
【修复】修复只开换肤模式仍加载 BotHider、BotVision、RayTrace 等受管 native BOT 扩展的问题。

【其他】B站贝壳继续按原始单位展示；当前后台可见记录和暂定展示折算不代表平台完整充电总额。
【其他】本版本继续面向助手启动的本地 `-insecure` BOT、创意工坊和只开换肤场景，不适用于官匹、5E、完美或其他受保护环境。
【其他】Tauri updater 使用 `.sig` 更新签名；该签名与 Windows Authenticode 代码签名属于不同机制，安装器是否显示 `NotSigned` 需要独立报告。
【其他】本次本地签名候选尚未上传 GitHub、R2、D1，也未启用线上 updater feed；线上发布前仍需完成真实安装、下载和玩家设备验收。
