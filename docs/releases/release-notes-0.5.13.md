# CS2 人机增强助手 0.5.13 更新日志

【新增】新增水墨江南 Three.js 鸣谢长廊，将开屏动画与版本彩蛋统一到同一场景，依次展示上游项目、公开赞助与公开鸣谢。
【新增】新增按牌子数量自适应的长廊布局，支持牌子增加、减少、类别为空和大数量数据，不再将所有牌子固定挤在同一个圆环中。
【新增】新增“确认 CS2 已关闭并解锁”功能。遇到系统残留、挂起或无法结束的 `cs2.exe` 时，玩家确认游戏实际已退出后，可在当前助手会话内恢复被 CS2 运行状态锁定的配置操作。
【新增】新增 CS2 手动确认状态的统一运行时管理，覆盖 Panel 配置、BOT 强度工坊、本地对局录制、MapRotation、定制插件维护和库存换肤插件维护等本地操作。
【新增】新增 BOT 强度工坊的编辑文本结构校验，能够在保存前识别不可见控制字符、未闭合引号、空 key/value、异常区块和多余 `End`。
【新增】新增 BOT 强度工坊独立的重打包失败与回读失败错误分类，便于玩家区分编辑内容、VPK 重打包和文件回读问题。
【新增】Demo 复盘新增“战术回放工作台”界面，整合地图回放、热力图、上下文状态、时间轨、阵营图例和空间数据检查器。
【新增】概览页升级为“本地对局启动台”，集中显示 CS2 目录、资源环境、进程状态、启动模式、BOT 难度、本地录制和主启动操作。
【新增】新增“只开换肤”启动模式：保留 Inventory Simulator 库存换肤，停用 CS2AS05 BOT 插件，让创意工坊地图使用地图和 CS2 原生 BOT 逻辑。
【新增】库存换肤页新增“启动只开换肤”入口，进入本地创意工坊或闯关地图前无需再切换 BOT 难度。
【新增】新增只开换肤模式的插件隔离与恢复状态记录，支持切回 BOT 模式或在线模式时恢复受管插件。

【优化】开屏动画默认关闭，保留用户已有的明确设置；用户可以在设置中按需开启，或从版本彩蛋进入同一鸣谢长廊自由浏览。
【优化】鸣谢牌面按来源使用青黛、暖金和朱砂视觉区分，并优化窄窗口下的牌子导航、镜头聚焦与可读性。
【优化】人工确认 CS2 已关闭后，不再只解锁单个人机工坊；所有原本仅因 CS2 运行状态而锁定的本地配置操作均可连续使用，不需要每次保存重复确认。
【优化】手动确认状态只保存在当前助手进程内，绑定当前 CS2 目录并自动过期，不写入配置文件、数据库或浏览器存储。
【优化】BOT 强度工坊保存流程改为从源 VPK 只读读取，并通过 VPKEdit 独立输出候选 VPK，再进行提取回读和原子替换，减少候选包原地修改造成的回读失败。
【优化】BOT 强度工坊错误提示改为面向玩家的中文说明，明确提示内容格式、重打包、回读、临时目录和提取失败的下一步操作。
【优化】BOT 强度工坊继续使用独立提取目录、并发保护、写入探测、有限重试和陈旧目录清理，降低重复操作造成的临时文件冲突。
【优化】地图回放和热力图采用统一的战术工作台布局，地图成为主要观察区域，控制参数、时间轨和状态信息层级更加清晰。
【优化】概览页采用状态优先的本地对局启动布局，在线模式、BOT 模式、`-insecure` 边界和资源状态显示更加明确。
【优化】预览、概览和状态条在窄窗口下采用响应式布局，保留关键操作、焦点状态、图标名称和减少动效支持。
【优化】NadeSystem 恢复上游 CS2-Bot-Improver v1.4.4 投掷行为，`bot_nades` 五档不再叠加 CS2AS05 自定义投掷节奏限制。
【优化】`more`、`normal`、`less` 模式不再受项目额外的 BOT 5 秒间隔、队伍 0.5 秒间隔、开局预算、每回合数量和队伍烟雾额度限制。
【优化】BOT 难度设置在“只开换肤”模式下明确为不接管，避免玩家误以为调整难度可以修复创意工坊地图逻辑。

【修复】修复鸣谢数量变化后牌子可能互相遮挡、空类别残留、彩蛋镜头无法定位以及大数量导航横向溢出的问题。
【修复】修复开屏和彩蛋场景各自维护不同牌子布局导致数据顺序和视觉表现不一致的问题。
【修复】修复 BOT 强度工坊保存候选 VPK 原地修改后，回读 `botprofile.db` 偶发提取失败的问题。
【修复】修复 BOT 强度工坊将编辑内容错误包装为工具依赖无效，导致玩家无法判断真实失败阶段的问题。
【修复】修复 BOT 强度工坊修改 `ReactionTime`、`AttackDelay` 等字段后，重打包候选包不稳定导致保存失败的问题。
【修复】修复 CS2 残留挂起进程导致助手持续锁定 Panel、BOT 工坊和其它本地配置操作的问题。
【修复】修复玩家确认 CS2 实际已关闭后，部分页面仍然保留旧的 `cs2Running` 锁定状态的问题。
【修复】修复 Demo 预览页面控制区、地图区域和时间轨层级分散，导致长时间复盘时信息查找不顺畅的问题。
【修复】修复概览页面环境状态、启动操作和配置入口分散，导致玩家难以判断下一步动作的问题。
【修复】修复 BOT 工坊前端显示错误过长、缺少可执行下一步提示的问题。
【修复】修复 `bot_nades more` 到 `bot_nades less` 实际投掷数量异常偏少的问题，移除自定义 NadePacingPolicy 对上游投掷路径的拦截。
【修复】修复 `bot_nades max` 表面无模式上限但仍被隐藏节奏、开局和每 BOT 硬限制影响的问题。
【修复】修复创意工坊闯关地图中 BOT 行为被 CS2AS05 自定义插件接管，导致 BOT 全灭后地图无法正常推进下一关的风险。
【修复】修复从旧版本升级后首次选择“只开换肤”缺少 SkinOnly gameinfo 文件，导致模式切换失败的问题。
【修复】修复从 BOT/只开换肤状态切回 Online 时，启动前错误要求当前活动 gameinfo 已经是官方文件的问题。
【修复】修复只开换肤仍加载 BotHider、BotVision、RayTrace 等 native BOT 扩展，导致插件头像和 BOT 行为残留的问题。

【其他】B站贝壳仍按原始单位展示；当前后台可见记录和暂定展示折算不代表平台完整充电总额。
【其他】本版本安装器使用 Tauri updater `.sig` 签名；`.sig` 与 Windows Authenticode 代码签名属于不同机制。
【其他】本版本的手动确认只解除“CS2 运行状态锁”，不会自动结束进程，不会结束 Steam 或未知 PID，也不会替玩家启动新的 CS2。
【其他】人工确认不会跳过 VPK 备份、回读、原子替换、资源摘要、插件版本、Online `gameinfo.gi` 官方基线和其它既有安全校验。
【其他】本版本继续面向助手启动的本地 `-insecure` BOT 场景；Online 模式保持官方文件边界，不将本地 BOT 资源描述为官方在线能力。
【其他】Tauri updater 使用 `.sig` 更新签名；该签名与 Windows Authenticode 代码签名属于不同机制，Windows 安装器是否显示 `NotSigned` 需要独立报告。
【其他】BOT 强度、插件、地图回放、热力图和配置写入仍以真实 Windows/CS2 环境验收为最终依据，自动化测试和本地构建不能替代玩家设备验证。
【其他】`bot_nades` 的实际投掷数量仍受地图投掷点、BOT 经济、存活状态、视线、回合状态和 CS2 原生条件影响；本版本不承诺固定每回合数量。
【其他】“只开换肤”仍使用本地 `-insecure`，仅适用于本地创意工坊、闯关和 BOT 场景，不适用于官匹、5E、完美或其他受保护环境。
【其他】只开换肤会保留 Inventory Simulator 和 CounterStrikeSharp 基础运行时，隔离受 CS2AS05 管理的 BOT 插件及对应 Metamod 入口；切回 BOT/Online 时恢复这些受管文件。
