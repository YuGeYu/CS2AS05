# CS2 人机增强助手 0.5.14 更新日志

【新增】新增凉拌娱乐社区入口，支持玩家在线查看社区状态、加入交流和使用社区相关功能。
【新增】新增 BOT 发言配置管理，可在助手内读取、编辑和保存 CS2BotLlmChat 配置。
【新增】新增体积烟功能开关，玩家可以在安装与诊断中独立启用或关闭 BotVision，不影响其他 BOT 插件文件。
【新增】新增 0.5.14 版本开屏与版本彩蛋内容，继续使用统一的鸣谢场景展示上游项目、公开赞助和公开鸣谢。
【新增】新增 CS2 关闭后的自动恢复流程：普通关闭等待 2 秒后自动执行强制关闭，并保留常驻的人工确认解锁入口。

【优化】社区页面增加在线状态、连接状态和玩家向提示，减少网络异常时的误解和重复操作。
【优化】安装资源与插件版本校验适配上游 CS2-Bot-Improver v1.4.4 资源结构，保留现有备份、回读和安全检查。
【优化】CS2 关闭流程会在强制阶段反复清扫所有当前 `cs2.exe` 进程，不再要求玩家再次点击“确认强制关闭”。
【优化】人工确认入口常驻展示，即使当前未检测到 CS2 也可以直接确认并解锁所有受 CS2 状态影响的助手控件。
【优化】主界面、社区、资源库和版本内容的状态提示统一为更清晰的中文玩家向表达，并继续保留窄窗口布局和减少动效支持。

【修复】修复 DPAPI 密钥文件带首尾换行时可能导致签名密码读取失败、最终只生成未签名安装候选的问题。
【修复】修复强制关闭后仍残留多个 `cs2.exe` 进程时只处理首轮进程、导致助手继续锁定的问题。
【修复】修复关闭命令异常或 CS2 状态检测异常时玩家缺少人工解锁入口的问题。
【修复】修复关闭 CS2 后部分页面仍保留旧运行状态、未及时开放启动和配置控件的问题。
【修复】修复体积烟关闭后仅删除加载入口、但状态无法持久回读的问题。
【修复】修复社区在线人数和连接状态在刷新、断线恢复时可能显示过期结果的问题。

【其他】本版本继续面向助手启动的本地 `-insecure` BOT、创意工坊和只开换肤场景，不适用于官匹、5E、完美或其他受保护环境。
【其他】CS2 关闭后的人工确认是玩家对实际游戏状态的最终确认；确认只解除助手的运行状态锁，不会结束 Steam、未知 PID 或其他非 `cs2.exe` 进程。
【其他】Tauri updater 使用 `.sig` 更新签名；该签名与 Windows Authenticode 代码签名属于不同机制，安装器是否显示 `NotSigned` 需要独立报告。
【其他】BOT 发言、体积烟、社区在线状态和真实 CS2 行为仍以玩家设备上的实际运行结果为准，自动化构建与测试不能替代真实设备验收。
