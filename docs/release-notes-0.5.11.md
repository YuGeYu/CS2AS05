# CS2 人机增强助手 0.5.11 更新日志

【新增】内置“人机强度工坊”，可从 Low、Medium、High 三档 VPK 提取 `botprofile.db`，阅读并复制为自定义强度档案。
【新增】支持编辑自定义 `botprofile.db`，保存时自动回写 VPK、二次提取校验并保留历史备份。
【新增】支持将自定义 BOT 强度档案应用到当前本地 BOT 模式，并在应用前自动备份当前活动档案。
【新增】随应用打包并校验 VPKEdit CLI sidecar，玩家无需另行下载 VPKEdit GUI 即可管理 BOT 强度。
【新增】上游 v1.4.4 整包能力对齐，包含新版 BOT 投掷相关插件、资源 manifest、插件版本门禁与安装诊断链路。

【优化】BOT 插件安装、升级、卸载和回滚流程统一基于 v1.4.4 整包，减少旧版 DLL 覆盖新版上游文件的风险。
【优化】Online 与 BOT 模式继续使用明确的官方 `gameinfo.gi` 边界，定制功能不会修改或污染在线模式文件。
【优化】BOT 强度工坊增加只读基线、当前使用状态、工具校验、保存回读状态和错误提示，避免显示虚假成功。
【优化】自定义 VPK 的保存与应用采用临时文件、原子替换、SHA-256 回读和备份策略，降低中断或文件占用造成的损坏风险。
【优化】优化窗口拖动、最小化、关闭和 CS2 进程状态处理，减少退出竞态导致的无响应。
【优化】暗色模式调整为更纯粹的墨色层次，收敛偏蓝色背景并改善长时间使用时的对比度。
【优化】开屏动画和鸣谢彩蛋改为轻量本地静态数据，不再持续查询官网赞助接口，同时保留更新、公告和完整项目鸣谢展示。
【优化】赛后战报、表现雷达、Demo 自动录制、人机预设、BOT 物品和丢刀等本地 BOT 工作流继续沿用统一的状态校验与安全写入策略。

【修复】修复 BOT 自动安装时内置资源缺少 `gameinfo` manifest 导致安装失败的问题。
【修复】修复安装与诊断页面将定制资源包错误显示为基于上游 v1.4.3 的版本信息，现统一显示 v1.4.4。
【修复】修复人机强度工坊尝试读取 VPK 外部不存在的 `botprofile.db`，改为真实提取 VPK 内部条目。
【修复】修复 VPKEdit sidecar 未接入实际保存链路的问题，现支持创建、保存、校验和应用自定义档案。
【修复】修复自定义 VPK 保存时覆盖原文件而缺少回读保护的问题，校验失败时保留原档案不变。
【修复】修复安装 ZIP 结构校验对隐式 `addons/`、`cfg/`、`overrides/` 目录识别不完整的问题。
【修复】修复 BOT 模式可能加载旧版定制 NadeSystem、MapRotation 或插件 marker 的问题，安装前后统一执行版本与 payload 门禁。
【修复】修复开屏和彩蛋内容在较小窗口中无法完整查看的问题，增加稳定滚动区域并确保所有项目与赞助者可浏览。

【其他】0.5.11 正式版本面向助手启动的本地 `-insecure` BOT 场景；Online 模式保持正常启动契约，不修改官方 `gameinfo.gi`。
【其他】VPKEdit CLI 以 MIT 许可证组件形式随应用分发；本版本不包含 VPKEdit GUI，也不会后台启动 VPKEdit 主界面。
【其他】安装程序提供 Tauri updater `.sig` 更新签名；该签名不等同于 Windows Authenticode，Windows 安装器仍可能显示未进行代码签名。
【其他】自定义 BOT 强度的实际反应、瞄准和投掷表现以玩家在真实 CS2 BOT 对局中的测试为准，程序不会把本地构建或自动化检查冒充为游戏行为验收。
