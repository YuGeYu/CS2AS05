# CS2 人机增强助手 0.6.0 更新日志

【新增】

- 新增资源阁与本地支持推送：助手运行到第 10、20、30 分钟及之后每 10 分钟，会展示一次可手动关闭的分享窗口。
- 新增资源阁资源推送，从资源阁已发布资源中选取最新 10 项并按顺序展示。
- 新增“凉拌娱乐”QQ群入口与微信赞赏码本地推送，按顺序轮换展示；资源阁暂时不可用时自动使用本地推送。
- 新增 Inventory Simulator 3.3.0 饰品功能上游资源，支持库存换肤工作流使用新的上游发布版本。
- 新增只开换肤启动前检查：库存换肤状态异常时会先引导处理，确认后需要重新点击“启动 CS2”。

【优化】

- 更新内置 CS2 BOT 上游资源包，并同步新的资源版本标识与安装流程。
- 自动换图默认关闭，减少首次启动时对玩家配置的干扰。
- BOT 物品页面统一保持开启并锁定设置，明确提示相关细分功能仍在完善中。
- 本地对局记录和自动录制 Demo 仅在 BOT 模式启用，其他模式下自动关闭且不允许误改。
- 启动 CS2 的只开换肤模式会先复核库存换肤状态，降低插件状态不一致造成的启动失败。
- 开屏动画和彩蛋页面改为本地硬编码内容，不再联网获取赞助者和 B 站充电信息；同时取消赞助者昵称展示。
- 开屏提示、资源入口和支持入口统一使用更清晰的中文说明，并改善模态窗口焦点、键盘关闭和页面滚动体验。

【修复】

- 修复 InventorySimulator.dll 资源摘要校验失败问题，重新同步 3.3.0 资源及其依赖、调试符号和 manifest 信息。
- 修复内置定制资源包版本 marker 与正式版本不一致的问题，避免覆盖更新时出现资源版本误判。
- 修复内置资源结构校验所需条目缺失导致的定制插件包拒绝更新问题。
- 修复只开换肤模式在库存换肤状态未准备完成时仍继续启动 CS2 的问题。
- 修复概览页 Demo 自动录制在非 BOT 模式下仍可能被启用的问题。
- 修复启动页在网络不可用时依赖远程赞助数据导致展示不稳定的问题。

【其他】

- 正式版本号更新为 `0.6.0`。
- 本版本保留上游资源的许可证、版权和归属信息，随安装包提供对应资源内容。
- 发布安装器同时生成 Tauri updater `.sig` 签名文件；Windows 安装器本身仍以 Authenticode 未签名状态交付。
- 本版本安装器用于正式发布准备和内部测试，真实 CS2 安装、启动及游戏内效果仍需在目标玩家设备上完成最终验收。
