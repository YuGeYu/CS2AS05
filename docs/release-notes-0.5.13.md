# CS2AS 0.5.13 更新日志

【新增】新增水墨江南 Three.js 鸣谢长廊，将开屏动画与版本彩蛋统一到同一场景，依次展示上游项目、公开赞助与公开鸣谢。
【新增】新增按牌子数量自适应的长廊布局，支持牌子增加、减少、类别为空和大数量数据，不再将所有牌子固定挤在同一个圆环中。
【新增】

- 新增水墨江南风格的 Three.js 开屏场景，镜头自动经过上游项目、赞助与公开鸣谢牌子。
- 新增与开屏共用同一场景的版本彩蛋长廊，可通过牌子导航和方向键自由选择浏览对象。
- 新增线上公开赞助与鸣谢数据读取，支持上游项目、平台、单位、当前可见数量、来源和记录范围等信息展示。
- 新增 B站充电鸣谢展示：记录昵称为 SoyO_official，展示当前后台可见的 20.16 贝壳，并明确标注暂按 1 贝壳 = 1 元人民币折算。
- 新增低性能模式与 WebGL 失败回退，降低不同玩家设备上的运行门槛。

【优化】开屏动画默认关闭，保留用户已有的明确设置；用户可以在设置中按需开启，或从版本彩蛋进入同一鸣谢长廊自由浏览。
【优化】鸣谢牌面按来源使用青黛、暖金和朱砂视觉区分，并优化窄窗口下的牌子导航、镜头聚焦与可读性。
【优化】

- 优化赞助与鸣谢信息层级，将上游项目、赞助和鸣谢统一为同一套牌子展示体系，不再单独拆分鸣谢页面。
- 优化线上数据访问：助手端增加 15 分钟原生缓存和并发请求复用，官网接口增加边缘缓存、ETag 和 304 条件响应，减少 D1 查询压力。
- 优化开屏默认行为：新用户默认跳过开屏动画；已有用户的明确覆盖设置继续优先，以用户选择为准。
- 优化牌子镜头过渡、焦点高亮、移动端横向导航和键盘方向键浏览体验。
- 优化金额语义展示，平台单位优先于兼容字段，避免将 B站贝壳记录误读为用户完整人民币赞助总额。

【修复】修复鸣谢数量变化后牌子可能互相遮挡、空类别残留、彩蛋镜头无法定位以及大数量导航横向溢出的问题。
【修复】修复开屏和彩蛋场景各自维护不同牌子布局导致数据顺序和视觉表现不一致的问题。
【修复】

- 修复新平台单位鸣谢记录无法被助手正确解析的问题。
- 修复 `amountCents` 为空时官网后台展示和类型检查失败的问题。
- 修复官网公开赞助接口无法利用客户端条件请求的问题。
- 修复开屏与版本彩蛋各自维护不同场景、展示口径不一致的问题。

【其他】B站贝壳仍按原始单位展示；当前后台可见记录和暂定展示折算不代表平台完整充电总额。
【其他】本版本安装器使用 Tauri updater `.sig` 签名；`.sig` 与 Windows Authenticode 代码签名属于不同机制。
【其他】

- 版本号保持为 0.5.13。
- 鸣谢金额说明以当前可核实记录为准；公开记录不代表用户在平台上的完整充电总额。
- 本版本继续保留上游项目 `ed0ard/CS2-Bot-Improver` 的项目鸣谢与许可证信息。
