# CS2 人机增强助手 0.5.7 更新日志

## 【新增】

- 【新增】皮肤工坊，按上游 PlayerSkinMod 1.8.2 对齐武器、刀具、手套、角色、音乐盒、贴纸和挂件配置能力。
- 【新增】皮肤工坊支持 CT / T 阵营分别保存装备搭配，支持自定义搭配与每次重生随机两种装备模式。
- 【新增】皮肤工坊编辑器支持磨损、模板、命名、StatTrak、贴纸槽位与挂件参数配置，并提供上游命令和安全说明。
- 【新增】皮肤图片受控缓存、来源校验、失败回退和加载状态提示，减少外部图片异常对工作台的影响。
- 【新增】录像库为每个 Demo 提供删除入口，并使用应用内确认流程删除对应录像及其分析记录。
- 【新增】开屏与彩蛋场景统一为“贡献陈列馆”，支持第一人称探索、明亮展厅、贡献鸣谢卡片和中心展品展示。
- 【新增】贡献陈列馆中心展品替换为唐代彩绘仕女俑，支持 GLTF、Draco 和 Basis Universal 资源链加载。
- 【新增】安装与诊断页面支持当前 Windows 用户级开机启动开关，无需管理员权限。
- 【新增】安装与诊断页面新增“清除数据”，仅清理助手缓存、日志和界面偏好，不删除 CS2 文件、插件、Demo 或复盘数据库。
- 【新增】安装与诊断页面新增故障提交表单，用户可以填写故障详情，并随工单上传经过脱敏和裁剪的诊断日志。
- 【新增】安装与诊断页面保留更新检查、官网入口、意见反馈、关于与来源及原版 Panel 兼容入口。
- 【新增】录像库继续提供 CS2 播放、资源管理器定位、赛后战报和回放会话隔离能力。

## 【优化】

- 【优化】安装与诊断页面重新整理信息层级、维护操作和响应式布局，桌面端与窄窗口下均保持可用。
- 【优化】官网故障工单后台刷新逻辑，由固定 30 秒轮询调整为首次加载、手动同步、重新聚焦或页面恢复可见且超过 60 秒后同步；工单操作后只刷新相关区域。
- 【优化】开屏鸣谢卡片尺寸和旋转节奏调整，支持者数据获取失败时保留明确的等待或回退状态，不阻塞主程序进入。
- 【优化】贡献陈列馆场景整体提亮，增加暖白主光、轮廓光和青金色展厅层次，使展品轮廓和彩绘残留更清晰。
- 【优化】中心展品根据真实世界包围盒自动缩放、水平居中并贴合展台，加载时显示占位反馈，避免出现空展台。
- 【优化】Demo 分析与赛后战报增加最新文件、完整指纹、解析状态和可展示报告门禁，降低旧 Demo 或半成品报告被误选的概率。
- 【优化】皮肤工坊编辑草稿与保存流程采用结构化数据适配，兼容上游配置字段并保持 CT / T 配置隔离。
- 【优化】客户端故障日志上传增加用户目录、密码、令牌、私钥和授权头等敏感信息的脱敏与长度限制。

## 【修复】

- 【修复】修复皮肤工坊编辑完成时结构化克隆失败导致 `DataCloneError` 的问题。
- 【修复】修复皮肤工坊图片加载失败后缺少反馈、编辑器出现空白状态的问题。
- 【修复】修复贡献陈列馆中心展品资源链不完整导致模型不可见或只显示空展台的问题。
- 【修复】修复旧“青冥试剑”彩蛋入口残留，统一切换到贡献陈列馆场景。
- 【修复】修复录像库删除操作缺少逐条入口和确认流程的问题。
- 【修复】修复 Demo 播放、CS2 实时对局和赛后自动战报之间的会话竞态，避免回放退出误触发赛后战报。
- 【修复】修复安装与诊断页手动查看诊断日志入口与当前维护流程不一致的问题；诊断日志改为仅在故障提交时自动附带。
- 【修复】修复清除助手数据后残留前端缓存状态的问题；清除范围仍不包含 CS2 文件、插件、Demo 和复盘数据库。
- 【修复】修复开机启动状态在助手再次打开后仍显示为未安装或未配置的问题，改为读取 Windows 当前用户的真实状态。
- 【修复】修复故障提交日志可能携带本机敏感路径或凭据片段的问题。

## 发布说明

- 当前应用版本：`0.5.7`。
- 本地发布候选已生成 NSIS 安装器和 Tauri updater `.sig`。
- Windows Authenticode 状态仍为 `NotSigned`；它与 Tauri updater 签名属于不同机制。
- 本版线上发布前仍需完成远端更新清单、对象回读和真实客户端更新验签。
