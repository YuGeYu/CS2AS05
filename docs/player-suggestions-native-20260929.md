# 玩家建议原生页面（2026-09-29）

## 变更

- 导航新增“玩家建议”入口，使用原生 Vue 页面，不嵌入官网网页。
- 桌面端复用官网 `/api/ideas`、`/api/auth/me` 及意见管理接口，功能与官网玩家建议页保持一致。
- 未登录时可以查看公告、分区和公开建议；登录后可以提交、修改、删除自己的建议。
- 管理员账号可以回复建议、创建/改名/删除意见分区；故障分区仍遵循官网锁定规则。
- 官网意见页的用户可见名称统一为“玩家建议”，保留 `/idea` 地址和原有 API 兼容性。

## 安全边界

- 官网账号凭据和会话 Cookie 只在 Tauri Rust 后端处理，不传给 Vue 页面。
- 一键注册复用官网已有 quick-register 接口，并将凭据写入助手既有账号存储。
- 所有写操作通过官网原有权限校验和每日限额执行，桌面端不绕过服务端授权。
