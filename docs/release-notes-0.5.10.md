# CS2 人机增强助手 0.5.10 更新日志

【新增】库存模拟器 3.1.0 工作流，创建并装备库存后可用于助手启动的本地 BOT 对局。
【新增】库存环境检测、一键启用、安全移除、中文教程及饰品工坊入口，插件与游戏状态更清晰。
【新增】MapRotation 地图轮换能力，支持默认配置、自动换图延迟与 `lbtv_map_next` 手动换图。
【新增】Demo 来源识别与解析安全门禁，创意工坊及来源不明 Demo 会保留文件并明确跳过原因。
【新增】赛后战报支持与主程序一致的主题、配色、圆角和密度设置，并采用 LBRating 2.0 评分标识。
【新增】表现雷达基础排名与多玩家对比展示，支持更高表现分的可视化和雷达缩放控制。
【新增】基于 Steam 官方 `gameinfo.gi` 整理 Online 与 WithBots 资源变体，并随安装包提供 Low、Medium、High 三档本地 BOT 配置资源。

【优化】饰品系统统一为单一 Inventory Simulator 引擎，迁移时精确清理旧 PlayerSkinMod 与旧缓存，避免多套插件同时接管武器实体。
【优化】紧凑、标准、宽松布局及全局圆角设置，减少侧栏与状态栏留白并改善不同窗口尺寸下的阅读空间。
【优化】开屏鸣谢与贡献陈列馆的场景范围、展牌环和镜头布局，展示内容更舒展清晰。
【优化】MapRotation 默认配置读取与回合结束后的换图时序，安装升级时保留玩家已有配置。
【优化】LBRating 2.0 以每回合击杀、伤害、存活和助攻综合评估比赛影响，战报页统一显示报告版本。
【优化】客服、安装诊断和 CS2 进程状态链路，减少退出竞态并保留可审计的错误上下文。
【优化】Online 与 BOT 模式切换增加可信 `gameinfo.gi` 摘要校验，异常时先阻止写入并提供明确恢复提示。
【优化】将自动换图默认状态从概览页移至主题设置中的开发中说明入口，减少启动时无必要的状态回读，并让功能状态与真实插件运行状态的边界更清晰。
【优化】资源刷新完成后自动重建当前版本插件 marker，确保插件版本、资源摘要与程序版本保持一致。

【修复】修复开屏动画及贡献陈列馆相邻展牌折叠、遮挡的问题。
【修复】修复 CS2 短暂漏检时提前结束对局、过早扫描 Demo 或生成不完整战报的问题。
【修复】修复创意工坊或来源不明 Demo 被误送入解析队列的问题。
【修复】修复移除库存插件时 CS2 仍运行导致文件占用、配置残留或状态异常的问题。
【修复】修复表现雷达超过基准时图形和数值被错误压回固定上限的问题。
【修复】修复旧版 K/D 权重过高导致低产出保活玩家评分反超高击杀、高伤害玩家的问题。
【修复】修复独立战报窗口无法继承主程序外观偏好，以及旧评分报告被误当作新版本报告的问题。
【修复】修复安装或升级后首次进入 Online 模式时，可信官方 `gameinfo.gi` 基线缺失而需要重复验证游戏文件的问题。
【修复】修复 0.5.10 自动安装 BOT 插件后仍读取到 0.5.9 版本标记，导致本地 BOT 模式无法启动的问题。
【修复】修复 MapRotation 未严格识别助手写入的 `{"enabled":false}`，导致玩家停用自动换图后重启插件仍继续换图的问题；无效配置会明确记录原因并采用安全回退。
【修复】修复资源刷新后插件 marker 仍保留旧版本号，导致 BOT 模式自动安装后被版本门禁拒绝的问题。

【其他】库存模拟器与地图轮换仅服务助手启动的 `-insecure` 本地 BOT 场景，不用于官匹、竞技平台或受 VAC 保护的对局。
【其他】本版本提供 Tauri updater `.sig` 更新签名；该签名与 Windows Authenticode 代码签名属于不同机制。
【其他】升级安装会保留玩家已有的 MapRotation 配置，首次安装使用安全的默认开启设置与 15 秒自动换图延迟。
【其他】自动换图默认状态入口当前仅提供只读说明，不会修改配置；待插件兼容修复完成真实 CS2 验证后再恢复可用状态。
【其他】Medium 档 BOT 反应与射击强度仍以真实 CS2 BOT 验收为准；本版本不将资源构建结果等同于行为验证。
