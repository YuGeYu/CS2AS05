# CS2 人机增强助手 0.6.1 更新日志

【新增】

- 新增“玩家建议”原生页面，导航栏新增独立入口，不再通过嵌入网页访问意见功能。
- 新增与官网玩家建议页一致的公告、建议分区、建议列表和管理员回复展示。
- 新增登录、官网一键注册、提交建议、修改建议、删除建议和退出登录流程。
- 新增管理员建议回复、建议分区新增、改名和删除能力，并保留故障分区状态展示。

【优化】

- 玩家建议页面统一使用“玩家建议”这一更清晰的用户向名称，官网 `/idea` 地址和原有接口保持兼容。
- 玩家建议的账号凭据和会话 Cookie 由 Tauri 后端安全处理，桌面页面只接收必要的账号状态和内容数据。
- 玩家建议页面适配桌面端窄窗口和键盘操作，补充加载状态、错误提示、删除确认和管理员操作反馈。
- 统一桌面端与官网的玩家建议文案、分区规则、管理员权限和提交限制。

【修复】

- 修复桌面端原先只能打开外部意见网页、无法在助手内完成建议提交和管理的问题。
- 修复桌面端建议操作无法复用官网登录态的问题，所有写操作现在统一经过官网服务端权限校验。
- 禁用概览页面“只开换肤”启动功能；由于技术限制，暂未开放此功能，避免用户进入不可用的启动流程。
- 修复 0.6.1 内置 BOT 插件 marker 与程序版本不一致的风险，资源包 marker 已同步为 `0.6.1`。

【其他】

- 正式版本号更新为 `0.6.1`。
- 本版本继续使用 Tauri updater 签名文件发布；Windows 安装器是否具备 Authenticode 签名与 updater `.sig` 分开记录。
- 玩家建议内容仍由官网服务端保存和审核，桌面端不绕过官网的登录、权限和每日提交限制。
