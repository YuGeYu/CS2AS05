# CS2 人机增强助手 0.5.12 更新日志

【新增】工作区导航分为“核心工作台”“BOT 工具”“复盘与扩展”“支持与维护”四组，功能入口更容易定位。
【新增】标题栏显示当前工作区上下文，并提供公告、外观设置和窗口控制的清晰分组。
【新增】桌面端支持收起与展开侧栏，收起后保留图标、悬浮提示和无障碍名称。
【新增】增加“跳转到主要内容”入口，键盘用户可以跳过导航直接进入当前页面。
【新增】安装与诊断页面提供环境诊断、操作状态和安装前置条件的集中反馈。
【新增】BOT 强度工坊增加工具状态缓存、提取任务隔离和并发保护，减少重复检测与临时文件冲突。
【新增】自定义 BOT 强度档案支持重命名、删除和可恢复归档，删除当前使用档案时自动恢复对应的内置难度。
【新增】队伍预设扩充至 42 支，新增 9z、FUT 等队伍配置。

【优化】统一标题栏、导航栏和响应式断点行为，在桌面、窄窗口和移动宽度下保持清晰的信息层级。
【优化】当前导航项同时使用语义状态、背景、边框和强调线反馈，不再依赖固定索引位移定位。
【优化】侧栏收起和导航点击采用短时可打断反馈，并在减少动效模式下自动降级。
【优化】安装、覆盖更新、卸载和故障处理流程集中展示进行中的操作和结果，降低误操作概率。
【优化】BOT 强度工坊的 VPK 提取使用独立工作目录和互斥保护，改善多次打开和重复提取时的稳定性。
【优化】BOT 强度工坊将 VPK 读取、编辑、保存和应用任务移出窗口主响应链路，快速切换档案时只保留最新请求结果。
【优化】删除自定义档案前增加活动状态、未保存修改、备份和内置基线恢复保护，避免误删当前 BOT 配置。
【优化】定制插件资源继续对齐 CS2-Bot-Improver v1.4.4 与 Panel v1.4.4，NadeSystem 资源链路保持同一上游基线。

【修复】修复标题栏品牌区域被整体隐藏后，辅助技术无法读取应用名称的问题。
【修复】修复导航分组、隐藏和排序场景下当前页面反馈可能错位的问题。
【修复】修复窄窗口导航仅显示无名称图标、普通用户难以识别入口的问题。
【修复】修复侧栏状态变化推动主内容区跳动的问题。
【修复】修复 BOT 强度工坊重复提取时共享临时目录可能互相覆盖的问题。
【修复】修复 BOT 强度工坊打开档案时未先确认 CS2 已退出的问题。
【修复】修复少数玩家因残留进程或安全软件瞬时占用而无法提取人机档案的问题，提取现在使用全新目录自动重试。
【修复】修复定制插件安装时“内置定制资源摘要不匹配”导致 BOT 模式无法安装的问题，资源包摘要校验值与新版 NadeSystem 资源包保持同步。
【修复】修复人机档案提取失败时错误提示与“工具缺失”混淆、无法判断原因的问题，现在使用独立错误码并附带现场信息。
【修复】修复 BOT 强度工坊旧提取目录长期堆积的问题，超过 48 小时的临时工作目录会被自动清理。
【修复】修复安装诊断页面缺少操作中状态和环境结论，导致用户无法判断下一步动作的问题。
【修复】修复打开、切换、保存和应用人机强度档案时窗口短暂无响应的问题。
【修复】修复公告、更新提示、人机强度工坊和外观设置出现时标题栏拖动区域被浮层截获的问题。

【其他】本版本继续面向助手启动的本地 `-insecure` BOT 场景；Online 模式保持官方 `gameinfo.gi` 边界，不修改在线模式文件。
【其他】本版本提供 Tauri updater `.sig` 更新签名；该签名与 Windows Authenticode 代码签名属于不同机制，Windows 安装器仍可能显示 `NotSigned`。
【其他】BOT 强度、投掷和插件行为以真实 CS2 BOT 对局为最终验收依据，自动化测试和本地构建不替代实机验证。
【其他】升级安装会保留玩家已有配置；安装、更新、卸载和回滚前会继续执行资源版本、哈希与备份保护。
【其他】删除的自定义档案会移入本机可恢复归档，不会删除其它档案、全局备份或玩家 CS2 文件。
